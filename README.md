# 💻 SQL Server – 57 Practice Problems

**📊 A collection of SQL solutions developed through practical exercises using Microsoft SQL Server.**

## 📌 Overview

This repository contains solutions to **57 SQL practice problems** from the book used in my SQL Server course.

The project focuses on strengthening SQL query-writing skills, understanding relational database concepts, and developing practical problem-solving abilities through hands-on exercises.

## 🛠️ Technologies & Tools

- 💾 Microsoft SQL Server
- 🖥️ SQL Server Management Studio (SSMS)
- 📝 Transact-SQL (T-SQL)

## 📚 Topics Covered

| # | Topic |
|---|---|
| 01 | 🔍 Basic SQL Queries |
| 02 | 📊 Aggregate Functions and Grouping |
| 03 | 🔗 Joins and Relationships |
| 04 | 📅 Filtering, Sorting, and Date Operations |
| 05 | 🧩 Subqueries and Common Table Expressions (CTEs) |
| 06 | 📈 Set Operators and Window Functions |

## 🎯 Objectives

- ✍️ Develop strong SQL query-writing skills.
- 🗄️ Understand relational database structures and relationships.
- 🔎 Practice data retrieval, filtering, and aggregation.
- 🧠 Apply SQL concepts to practical problems.
- 📊 Build a foundation for Data Analytics and Business Intelligence.

Each SQL script contains solutions organized by topic, making the exercises easy to navigate and review.
